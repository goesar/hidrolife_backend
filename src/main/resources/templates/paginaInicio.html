HidroLife

Sistema inteligente para el monitoreo y gestión de cultivos hidropónicos. HidroLife integra sensores, software y análisis de datos para permitir el seguimiento en tiempo real de las condiciones del cultivo, facilitando una toma de decisiones más precisa y eficiente.

¿Qué es HidroLife?

HidroLife es una plataforma tecnológica diseñada para optimizar la gestión de cultivos hidropónicos mediante el uso de sensores y herramientas de monitoreo digital. El sistema permite visualizar en tiempo real variables críticas del cultivo como pH, conductividad eléctrica (TDS), temperatura y humedad ambiental. Además de monitorear estas condiciones, HidroLife permite registrar cultivos, gestionar actividades realizadas durante su crecimiento y mantener un historial de datos que facilita el análisis del estado del sistema hidropónico.

Monitoreo de sensores

Consulta en tiempo real las mediciones de los sensores instalados en el sistema hidropónico. HidroLife permite monitorear variables clave como pH, conductividad eléctrica (TDS), temperatura y humedad, proporcionando información actualizada que facilita el control de las condiciones del cultivo.

Gestión de cultivos

HidroLife permite llevar un control del número de plantas, registrar las actividades realizadas durante el crecimiento del cultivo y mantener un historial organizado de la producción.

¿Cómo funciona HidroLife?

Los sensores instalados en el sistema hidropónico capturan información sobre variables críticas del cultivo, como el pH de la solución nutritiva, la conductividad eléctrica (TDS), la temperatura y la humedad ambiental. Estos datos son enviados a un microcontrolador que se encarga de transmitir la información al sistema HidroLife. Una vez recibidos, los datos son almacenados y procesados por la plataforma, permitiendo al usuario visualizar las mediciones, consultar el estado del cultivo y registrar las actividades realizadas dentro del sistema.

Tecnología utilizada

HidroLife integra diferentes tecnologías de hardware y software para permitir el monitoreo inteligente de cultivos hidropónicos.

Hardware

ESP32

Microcontrolador encargado de recibir la información de los sensores y transmitir los datos al sistema.

Sensores

Sensores utilizados para medir pH, TDS, temperatura y humedad.

Backend

Spring Boot

Framework utilizado para desarrollar la lógica del sistema.

Spring Security

Sistema de autenticación y control de acceso del sistema.

MySQL

Base de datos utilizada para almacenar la información del sistema.

Frontend

Thymeleaf

Motor de plantillas utilizado para generar las vistas del sistema.

Bootstrap

Framework CSS para construir la interfaz de usuario.

JavaScript

Permite agregar interacción dinámica en la plataforma.
