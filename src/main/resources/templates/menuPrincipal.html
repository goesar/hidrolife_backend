HidroLife es un sistema de monitoreo y gestión para cultivos hidropónicos que permite visualizar lecturas de sensores como pH, TDS, temperatura y humedad, además de registrar cultivos y actividades realizadas en el sistema.

Actualmente el sistema permite visualizar información proveniente de los siguientes sensores:
  • Sensor de pH
  • Sensor de TDS (Total de sólidos disueltos)
  • Sensor de temperatura
  • Sensor de humedad
Estos datos permiten evaluar el estado del cultivo en tiempo real.

Cuando un sensor detecta valores fuera del rango configurado, el sistema puede generar alertas para informar que las condiciones del cultivo pueden no ser óptimas.

Solo los usuarios con rol de administrador tienen permisos para modificar los rangos mínimos y máximos de los sensores. Los usuarios normales solo pueden visualizar los valores.

El sistema permite desactivar registros como cultivos, actividades o usuarios. Cuando un registro está desactivado:
  • Los usuarios normales no pueden verlo.
  • Solo los administradores pueden visualizarlo

En el módulo de gestión y control se pueden utilizar los filtros de búsqueda, que permiten consultar información por:
  • tipo de registro
  • valores específicos
  • rangos de fecha

Si no aparecen lecturas, se recomienda verificar:
  • que los sensores estén correctamente conectados
  • que el sistema de adquisición de datos esté funcionando
  • que exista conexión con el dispositivo que envía las lecturas
